# Política de segurança

## Versões com suporte

| Versão | Suporte de segurança |
| --- | --- |
| 1.0.x | Sim |
| Anteriores a 1.0 | Não |

## Como relatar uma vulnerabilidade

Não publique senhas, tokens, dados pessoais, procedimentos de exploração ou
outros detalhes sensíveis em uma issue pública.

Para relatar uma vulnerabilidade:

1. acesse a aba **Security** do repositório;
2. selecione **Advisories** e **Report a vulnerability**;
3. descreva o problema, o impacto esperado e uma forma segura de reprodução;
4. aguarde a confirmação antes de divulgar publicamente os detalhes.

Se a opção de relatório privado ainda não estiver disponível, abra uma issue
sem detalhes técnicos sensíveis solicitando um canal privado de contato.

O recebimento será confirmado assim que possível. A análise considerará o
impacto, a possibilidade de exploração e as versões afetadas. Uma correção e
orientações de atualização serão publicadas antes da divulgação completa
sempre que o problema for confirmado.

## Escopo

São especialmente relevantes vulnerabilidades relacionadas a:

- autenticação, autorização e gerenciamento de sessão;
- exposição de credenciais ou dados pessoais;
- injeção de comandos, SQL ou conteúdo executável;
- falsificação de requisições e controle de acesso;
- dependências vulneráveis e configuração insegura de implantação.

Problemas gerais de funcionamento, sugestões e dúvidas podem ser registrados
normalmente como issues públicas, desde que não contenham informações
sensíveis.
